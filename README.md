# 🏡 House Price Prediction Using Linear Regression

### SkillCraft Technology – Machine Learning Internship | Task 1

A Machine Learning project that implements **Linear Regression** to predict house prices using housing-related features. This project demonstrates the fundamentals of supervised learning, data preprocessing, regression modeling, and predictive analysis using Python.

---

## 📌 Project Overview

House Price Prediction is a supervised Machine Learning project designed to estimate property prices based on relevant housing attributes.

The project focuses on understanding relationships between input features and house prices using the Linear Regression algorithm.

The primary objective is to develop a predictive model that learns from historical housing data and generates price predictions.

## 🎯 Objectives

- Understand and implement Linear Regression.
- Explore and analyze housing datasets.
- Perform data preprocessing and feature selection.
- Train a Machine Learning regression model.
- Generate house price predictions.
- Understand the practical applications of predictive analytics.

## 🧠 Machine Learning Algorithm

**Linear Regression**

Linear Regression is a supervised Machine Learning algorithm used to predict continuous numerical values by establishing a relationship between independent variables and a dependent variable.

In this project:

- **Learning Type:** Supervised Learning
- **Problem Type:** Regression
- **Algorithm:** Linear Regression
- **Target Variable:** House Price
